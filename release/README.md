## ⚠️ Security — read this first

The keystore and its passwords are committed here **only** so you have everything
in one place. Treat them as secrets:

1. **Move the keystore and passwords somewhere safe** (a password manager / secure
   vault) and keep an offline backup.
2. Consider **removing them from git history** after you've saved a copy, and/or
   **rotating** the key.
3. **Enable Google Play App Signing** when you upload. With Play App Signing,
   Google holds the real app-signing key and this file is only your *upload* key —
   which can be reset by Google if it is ever lost or compromised.

If you lose the upload key **and** are not enrolled in Play App Signing, you will
not be able to publish updates under the same app, so back it up.

## How to publish

1. Go to the [Google Play Console](https://play.google.com/console) → create the
   app (or open the existing one) → **Production** (or **Internal testing**) →
   **Create new release**.
2. Opt in to **Play App Signing** when prompted.
3. Upload `oppuna-1.2.0-production.aab`.
4. Fill in the store listing (see `docs/APP_STORE.md`) and the feature graphic
   (`assets/feature-image.png`), then roll out.

## How this bundle was built (reproducing it)

The app uses the Expo managed workflow, so the native `android/` project is
generated on demand and is git-ignored.

```bash
# 1. Install JS deps
npm install

# 2. Place Gemma GGUF at assets/ai-model/model.gguf

# 3. Generate the native Android project
npx expo prebuild --platform android --no-install --clean

# 4. Point Gradle at the upload keystore (copy it into android/app/)
cp release/oppuna-upload-key.keystore android/app/oppuna-upload-key.keystore

# 5. Build the signed APK and bundle
cd android
./gradlew :app:assembleRelease :app:bundleRelease \
  -POPPUNA_UPLOAD_STORE_FILE=oppuna-upload-key.keystore \
  -POPPUNA_UPLOAD_STORE_PASSWORD=<store password> \
  -POPPUNA_UPLOAD_KEY_ALIAS=oppuna-upload \
  -POPPUNA_UPLOAD_KEY_PASSWORD=<key password>

# Outputs:
# - android/app/build/outputs/apk/release/app-release.apk
# - android/app/build/outputs/bundle/release/app-release.aab
```

Toolchain used: JDK 17, Android SDK Platform 36, NDK 27.1.12297006,
CMake 3.22.1, Gradle 8.14.3.

> Note: the `release` signing config is added to `android/app/build.gradle` after
> prebuild. Because `android/` is regenerated by `expo prebuild`, the canonical
> long-term approach is to build via EAS (`npm run build:production`) or to move
> to the bare workflow. This local build is provided as a ready-to-upload
> artifact.
