# Oppuna — Android release artifacts

This folder is reserved for **local, untracked** release outputs (APK/AAB) during development.
**Do not commit signing keys, passwords, or production bundles to git.**

## Application identity

| Field | Value |
| --- | --- |
| Application ID | `com.oppuna.app` |
| On-device model | Qwen2.5 1.5B Instruct Q4_K_M (~941 MB) via install-time Play Asset Delivery |

## Building for Google Play

1. Follow `docs/PRODUCTION_SIGNING.md` for secure signing credentials.
2. Place the GGUF at `assets/ai-model/model.gguf` (gitignored).
3. Build with EAS: `npm run build:production`
4. Upload the resulting AAB through Google Play Console internal testing first.

See `docs/PLAY_STORE_RELEASE_CHECKLIST.md` for the full release process.

## Historical / obsolete local artifacts

Files already present in this folder (for example older `*.aab` / `*.apks`) may be
**pre-Qwen / stale** builds that packaged a legacy GGUF and obsolete Gemma license
assets. Do not submit them. Rebuild after placing the current Qwen `model.gguf`,
then run `npm run verify:aab -- <fresh.aab>`.

## Local Gradle build (advanced)

The native `android/` project is generated by Expo prebuild and is gitignored.
Signing credentials must be supplied via environment variables or EAS — never committed.
See `docs/PRODUCTION_SIGNING.md`.
